# Guitar Journey

A local-first guitar practice app designed to help you progress through chords, transitions, rhythm, and real song practice.

## Features

- Choose a genre path: Worship, Blues, or Neo Soul
- Select songs or practice loops
- View required chords and tips
- Follow a guided practice session
- Track transition speed
- Mark songs as mastered
- Break songs into sections

## Getting Started

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in your terminal.

## Current MVP Scope

This first version is intentionally local and simple. It focuses on the core practice loop:

```txt
Choose path → choose song → practice chords → drill transitions → practice rhythm → play song sections
```
